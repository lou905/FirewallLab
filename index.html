How a firewall reads its rules (ACL)

1. Top to bottom. Each packet is checked against rule 1, then rule 2, and so on.
2. First match wins. As soon as a rule matches, the firewall stops looking. Order matters!
3. Implicit deny. If nothing matches, the packet is blocked. This is called default deny.
A rule checks: action (allow/deny), protocol (TCP/UDP), source IP, destination IP, and destination port.

Ports you'll need

22 SSH (remote admin login)
53 DNS (UDP, looks up website names)
80 HTTP (unencrypted web)
443 HTTPS (encrypted web)
445 SMB (Windows file sharing)
3389 RDP (Windows Remote Desktop)

This is a stateful firewall, so it remembers connections it allowed and lets the replies back in automatically. You only write rules for the traffic that starts the connection.
